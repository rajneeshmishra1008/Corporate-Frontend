# InnovateCorp – Corporate Website

A modern, responsive corporate website designed for **InnovateCorp**, showcasing enterprise software solutions, cloud architecture, UI/UX design, AI & machine learning, cybersecurity, and data analytics services.

The website focuses on a clean modern interface, responsive layouts, interactive components, and an engaging user experience.

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/rajneesh1008/innovatecorp.git
```

### 2. Navigate to the project

```bash
cd innovatecorp
```

### 3. Open the project

You can open `index.html` directly in your browser.

For a better development experience, use **VS Code Live Server** or another local development server.

## 🌐 Running with VS Code

1. Open the project folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
5. The website will open in your browser.

You can customize the website by editing:

### Company Information

Update company name, description, address, email, and phone number inside `index.html`.

Modify the service cards to add or remove services.

### Portfolio

Replace the existing portfolio projects with your own projects and images.

### Social Links

Replace the placeholder social-media links with your actual profiles.

## 🚀 Deployment

This project can be deployed using:

* GitHub Pages
* Netlify
* Vercel
* Cloudflare Pages

### GitHub Pages

1. Push the project to GitHub.
2. Open the repository **Settings**.
3. Select **Pages**.
4. Choose the main branch.
5. Select the root folder.
6. Save the configuration.
7. GitHub will generate your live website URL.
